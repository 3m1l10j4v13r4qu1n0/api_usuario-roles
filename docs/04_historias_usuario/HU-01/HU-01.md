Historia de Usuario N°1

**Como** usuario del ecosistema
**quiero** autenticarme con email y contraseña
**para** obtener un token JWT que me identifique y consultar mi perfil en `/auth/me`

**Tarjeta:** Login y recuperación del usuario autenticado. El email se normaliza a minúsculas; el login usa un mensaje genérico de error. Responde con los roles del usuario en el momento del login.

**Criterios de Aceptación (Gherkin):**
- Dado un usuario registrado con email en mayúsculas y una contraseña válida
  Cuando se autentica con el mismo email en minúsculas
  Entonces recibe un token JWT y sus roles
- Dado un usuario cuyo login NO se corresponde
  Entonces recibe 401 "Credenciales inválidas"
- Dado un usuario dado de baja (activo = False)
  Entonces recibe 401 "Credenciales inválidas"
- Dado un token JWT válido
  Cuando consulta `GET /auth/me`
  Entonces obtiene su id, email, nombre_usuario y roles

**Specification by Example:** casos de éxito (email con/sin mayúsculas), credenciales incorrectas
(401), usuario inactivo (401), consulta de `/auth/me` con token válido.

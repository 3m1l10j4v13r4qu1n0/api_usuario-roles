Historia de Usuario N°4

**Como** administrador o usuario propietario
**quiero** consultar un usuario por su ID
**para** conocer sus datos de forma puntual

**Tarjeta:** Obtener un usuario por ID. Protección por ownership: `ADMIN` o el **mismo usuario**
(`require_mismo_usuario_o_admin`). Si el id no existe → 404.

**Criterios de Aceptación (Gherkin):**
- Dado un ADMIN autenticado
  Cuando consulta `GET /usuarios/{id}` de cualquier usuario
  Entonces recibe 200 con los datos del usuario
- Dado un usuario autenticado que consulta su propio id
  Entonces recibe 200
- Dado un usuario autenticado (sin ADMIN) que consulta el id de OTRO usuario
  Entonces recibe 403
- Dado un id que no existe
  Entonces recibe 404 "El usuario ... no existe"

**Specification by Example:** ADMIN accede a cualquier usuario, ownership, 403 cruzado, 404 inexistente.

Historia de Usuario N°10

**Como** administrador
**quiero** quitar un rol a un usuario
**para** revocarle un permiso específico

**Tarjeta:** Quitado de rol a un usuario. Requiere rol `ADMIN`. Si el rol o el usuario no existen
→ 404. Al quitar, se **invalida el cache de estado** (USR-RN12): la revocación se refleja sin
re-login (verificado por integración).

**Criterios de Aceptación (Gherkin):**
- Dado un ADMIN autenticado, un usuario que posee un rol
  Cuando quita el rol
  Entonces recibe 200 con el usuario sin ese rol en `ids_roles`
- Dado un usuario con token vigente que antes tenía rol ADMIN
  Cuando un ADMIN le quita el rol ADMIN
  Entonces el próximo request ya NO tiene acceso ADMIN (sin re-login)
- Dado un rol inexistente
  Entonces recibe 404 "El rol ... no existe"
- Dado un usuario inexistente
  Entonces recibe 404 "El usuario ... no existe"
- Dado un usuario SIN rol ADMIN
  Entonces recibe 403

**Specification by Example:** quitado exitoso, revocación en caliente sin re-login, rol
inexistente (404), usuario inexistente (404), sin ADMIN (403).

`test_quitar_rol_revoca_sin_relogin` (integración).

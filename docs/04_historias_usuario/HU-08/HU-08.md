Historia de Usuario N°8

**Como** administrador
**quiero** listar los roles existentes
**para** conocer qué roles hay disponibles para asignar

**Tarjeta:** Listado de roles con rol `ADMIN` requerido. Si no hay roles, lista vacía.

**Criterios de Aceptación (Gherkin):**
- Dado un ADMIN autenticado
  Cuando consulta `GET /roles/`
  Entonces recibe la lista de roles
- Dado que no hay roles
  Entonces recibe una lista vacía
- Dado un usuario SIN rol ADMIN
  Entonces recibe 403

**Specification by Example:** listado con roles, lista vacía, 403 sin ADMIN.

**Acceptance TDD:** cubiertos por `test_uc8_listar_roles.py` (fakes) +
`test_flujo_completo.py` (integración, flujo asignar rol → listar roles).

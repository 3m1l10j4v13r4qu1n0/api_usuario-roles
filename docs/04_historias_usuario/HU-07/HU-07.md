Historia de Usuario N°7

**Como** administrador
**quiero** crear roles nuevos
**para** poder asignar más niveles de acceso a los usuarios

**Tarjeta:** Creación de rol con `nombre` obligatorio y `descripcion` opcional. Requiere rol
`ADMIN`. Normaliza textos (RN02) y rechaza nombres vacíos o duplicados (422).

**Criterios de Aceptación (Gherkin):**
- Dado un ADMIN autenticado y un nombre de rol nuevo
  Cuando crea el rol
  Entonces recibe 201 con el rol creado
- Dado un nombre de rol ya existente
  Entonces recibe 422 "El rol ... ya existe"
- Dado un nombre vacío o ausente
  Entonces recibe 422
- Dado un usuario SIN rol ADMIN
  Entonces recibe 403

**Specification by Example:** rol con descripción, sin descripción, normalización de bordes,
nombre vacío (422), nombre duplicado (422), sin ADMIN (403).

**Acceptance TDD:** cubiertos por `test_uc7_crear_rol.py` (fakes) +
`test_403_sin_rol_admin_en_endpoints_admin` (integración).

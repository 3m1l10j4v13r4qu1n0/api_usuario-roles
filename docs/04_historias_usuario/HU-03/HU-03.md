Historia de Usuario N°3

**Como** administrador
**quiero** listar los usuarios del sistema
**para** poder revisarlos y operar sobre ellos

**Tarjeta:** Listado de usuarios con rol `ADMIN` requerido (matriz de roles). Devuelve una lista;
si no hay usuarios, la lista es vacía.

**Criterios de Aceptación (Gherkin):**
- Dado un usuario con rol ADMIN autenticado
  Cuando consulta `GET /usuarios/`
  Entonces recibe la lista de todos los usuarios
- Dado que no hay usuarios registrados
  Entonces recibe una lista vacía
- Dado un usuario autenticado SIN rol ADMIN
  Entonces recibe 403
- Dado un request sin token
  Entonces recibe 401

**Specification by Example:** listado con usuarios, lista vacía, 403 sin rol ADMIN, 401 sin token.
